# InsightVault AI Backend

FastAPI backend for the InsightVault AI RAG knowledge intelligence API.

## Quick Start

```bash
cd backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Swagger docs:

```text
http://localhost:8000/docs
```

Run tests:

```bash
pytest
```
